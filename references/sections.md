# セクション構成

上から順に並べる。コンポーネント雛形は `assets/components/`。各セクションは全幅の `border-t` で区切る。

| # | セクション | 雛形 | 構造 |
|---|---|---|---|
| 1 | Header | `header.tsx` | 左ロゴ、右にナビ（4項目）＋ ghost「Log in」＋ 主ボタン。`h-14`、下罫線。スクロールで `sticky` |
| 2 | Hero | `hero.tsx` | 左: お知らせピル → H1（前半灰・後半白）→ ボタン2つ。右（lg以上）: 説明文を下揃えで置く |
| 3 | Bento grid | `bento-grid.tsx` | 4列×3行。各セル = 見出し + 件数 + 抽象モック。見出し位置はセルごとに変える（左上・中央・上など） |
| 4 | Logo cloud | `logo-cloud.tsx` | 見出し「Trusted by …」+ 6ロゴを1行。灰色の単色。ロゴはユーザー提供のみ |
| 5 | Features | `feature-grid.tsx` | 3列 + 4列の2段。見出し + 1行説明 + 下半分にミニ図解 |
| 6 | Wall of Love | `wall-of-love.tsx` | 4列の masonry。下端はフェードアウト、中央に「See more ⌄」 |
| 7 | FAQ | `faq.tsx` | 右半分に配置（左は空きまたは見出し）。アコーディオン、先頭だけ開く |
| 8 | CTA | `cta.tsx` | 中央揃え。H2「Stop … 灰＋白」+ ボタン2つ |
| 9 | Footer | `footer.tsx` | 左: ロゴ + 標語（等幅）+ SNS。右: 3列リンク。下段: 著作権 + クレジット |

## 寸法の目安

- Hero: 高さ `min-h-[420px]`、下端に罫線。
- Bento セル: 高さ `h-40`〜`h-48`、4列、`md` で 2列、`sm` で 1列。
- Features: 上段 3列・下段 4列。セル高 `h-72`。
- Wall of Love: 列間は罫線、カード内 `p-4`、アバター `size-8` 丸。本文 `text-sm`。
- FAQ: 質問 `py-4`、区切りは `border-b`。右向き `⌃/⌄` アイコンは `size-4`。
- CTA: `py-24`、H2 は `text-3xl`〜`text-4xl`。
- Footer: 4列グリッド、リンクは `text-sm` 灰。

## 内容の方針

- 件数（「14 blocks」）は `content.ts` の配列長から計算する。手書きしない。
- 顧客ロゴと Wall of Love は、実在の許可があるものだけ。無い場合はセクションごと省くか、「準備中」とせず出さない。
- フッター下段のクレジットは自分のサービスの情報だけ。
- Features のミニ図解は 3 種類を使い回す: アイコン配置（放射状）、リスト（アイコン + 名前）、コードブロック（ターミナル風）。

## レスポンシブ

- `sm`: 1列。縦罫線は左右の外枠だけ。
- `md`: 2列。ヒーロー右の説明文は H1 の下に回す。
- `lg` 以上: 仕様どおり。
- 外枠は `px-0`。内側の padding でそろえ、横スクロールを出さない。
